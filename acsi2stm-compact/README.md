# ACSI2STM-Compact

![ACSI2STM Compact Enclosure](https://sidecartridge.com/assets/images/products/acsi2stm/ACSI2STM2-TOP-CONNECTOR.png)

This folder contains the FreeCAD source files for the [ACSI2STM Compact](https://sidecartridge.com/products/acsi2stm-atari-st/) enclosure.

## Files
- `acsi2stm-compact-castillian.FCStd`: Main parametric FreeCAD model. Open this to view and edit the enclosure design.
- `acsi2stm-compact-castillian-BASE_BODY.stl`: STL mesh for the enclosure base.
- `acsi2stm-compact-castillian-LID_BODY.stl`: STL mesh for the enclosure lid.
- `revision.txt`: Revision identifier for this design set.


## STL Files

- Printable STL files are located in [here](https://www.thingiverse.com/thing:7011991).
