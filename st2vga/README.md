# ST2VGA FreeCAD design files

![ST2VGA](https://sidecartridge.com/assets/images/products/st2vga/ST2VGA-FRONT.png)

This folder contains the FreeCAD source files for the ST2VGA enclosure.

## Files
- `ST2VGA.FCStd`: Main FreeCAD model. Open this to view and edit the enclosure design.
- `revision.txt`: Revision identifier for this design set.

## STL files

- Printable STL files are located in [here](https://www.printables.com/model/1409863-st2vga-enclosure-sidecartridge).
