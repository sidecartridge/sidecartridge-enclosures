# ACSI2STM-MINI FreeCAD design files

![ACSI2STM Mini Enclosure](https://sidecartridge.com/assets/images/products/acsi2stm/ACSI2STM2-TOP-CONNECTOR.png)

This folder contains the FreeCAD source files for the [ACSI2STM Mini](https://sidecartridge.com/products/acsi2stm-mini-atari-st/) enclosure.

## Files
- `ACSI2STM-MINI-PARAMETRIC.FCStd`: Main parametric FreeCAD model. Open this to view and edit the enclosure design.
- `revision.txt`: Revision identifier for this design set.
