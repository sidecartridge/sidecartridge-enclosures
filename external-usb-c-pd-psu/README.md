# External USB-C PD PSU FreeCAD design files

![External USB-C PD PSU](https://docs.sidecartridge.com/sidecartridge-usb-c-pd-psu/assets/images/USB-C-PD-BOARD.png)

This folder contains the FreeCAD source files for the [External USB-C PD PSU](https://sidecartridge.com/products/usb-c-pd-psu-atari-st/) enclosure.

## Files
- `USB-PD-PSU-PARAMETRIC.FCStd`: Main FreeCAD model. Open this to view and edit the enclosure design.
- `revision.txt`: Revision identifier for this design set.
