# Internal USB-C PSU FreeCAD design files

This folder contains the FreeCAD source files for the Internal USB-C PSU enclosure.

These are the design files to close the AC power switch and the rocket switch openings when the Internal USB-C PSU board is installed inside an Atari ST computer.

## Files
- `USB-C-SOCKET.FCStd`: Main FreeCAD model. Open this to view and edit the enclosure design.
- `revision.txt`: Revision identifier for this design set.
