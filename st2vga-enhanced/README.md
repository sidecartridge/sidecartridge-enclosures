# ST2VGA Enhanced FreeCAD design files

![ST2VGA](https://sidecartridge.com/assets/images/products/st2vga/ST2VGA-FRONT.png)

This folder contains the FreeCAD source files for the ST2VGA Enhanced enclosure.

## Files
- `ST2VGA-ENHANCED.FCStd`: Main FreeCAD model. Open this to view and edit the enclosure design.
- `revision.txt`: Revision identifier for this design set.

## STL files

- Printable STL files are located [here](https://www.printables.com/model/1689407-st2vga-enhanced-enclosure-sidecartridge).
